# Riichi Mahjong Calculator

**雀算：四人立直麻将算番、算符、全场记分与逆转条件计算工具。** 支持电脑和 iPhone 界面，使用原生 HTML、CSS、JavaScript，无需安装依赖。

[电脑版网站](https://riichi-score-evans.plumbloom36.chatgpt.site/desktop.html) · [手机版网站](https://riichi-score-evans.plumbloom36.chatgpt.site/) · [完整说明](docs/使用说明.md)

| 功能 | 说明 |

| 犯规 | 各类型罚点、罚点去向、重打／继续；继续时本局不能和牌、不能立直、流局强制未听，庄家本局结束后过庄 |

| 结算报告 | 每局点数与顺位变化；终局返还点、供托、顺位马及首位奖励，终局分显示一位小数 |

## 使用

### 在线

电脑或手机直接打开上方网站。iPhone 推荐 Safari，可通过分享菜单添加到主屏幕。每人的记录存储于自己的浏览器，**不同设备不会自动同步**。

### 本地

下载仓库后打开 `app/index.html`；电脑专用入口为 `app/desktop.html`。文件必须保留在一起。便携文件 `app/雀算手机版.html` 内嵌脚本和样式。

手机文件管理器的 HTML 预览可能不运行 JavaScript；遇到这种情况请使用在线网站。本地文件和网站的浏览器存储互不自动迁移，重要记录请导出备份。

### 配置

在“规则与偏好”切换官方预设或自定义，修改后保存。可导入 `config/mleague.json` 或 `config/custom.json`。导入文件按当前应用行为作为可编辑的自定义配置载入；如需锁定官方参数，请在界面选择 M 联盟预设。

`config/ui-defaults.json` 说明默认界面参数；实际偏好通过界面设置。`config/hosting.example.json` 是无站点身份的静态托管模板，不包含认证信息。公开网站与本仓库分别管理，GitHub 提交不会自动更新现有 Sites 网站。

## 规则与适用范围

- M 联盟预设不采用累计役满、流局满贯及单役特殊双倍役满；不同役满允许按规则复合。官方依据：[M.LEAGUE 规则](https://m-league.jp/about/)。
- 大四喜、小四喜、大三元互斥；合法的字一色等复合保留。手动选役检查常见冲突，但不能替代对实际手牌的核实。
- 自定义包牌和犯规属于本项目支持的桌规，**不应视为 M 联盟官方规则**。关键碰牌来源、顺序及责任成立由使用者确认。
- 逆转计算为理论点数门槛，须有真实役及对应符数；不预测摸牌，不包括新立直供托、多响、包牌和后续连庄。
- 不识别真实牌桌或游戏画面；振听、立直合法性、鸣牌来源及特殊条件需人工确认。无三人麻将和地方古役自动判定。
- 离线缓存和本地存档可能被浏览器清理；保留导出备份。

## 独立逆转计算与直接点数输入
顶部“独立点差／逆转计算”在任何局都可打开，可载入当前牌桌或自行修改四家点数、庄家、本场及供托棒数，选择玩家与目标顺位查看自摸／各家直击的最低番符条件。试算不改变牌桌；南4及西场的原有面板保留。
主页面新增“直接输入点数”，也可在规则与偏好中设为默认。荣和输入放铳者支付额；庄家自摸输入每家支付额；闲家自摸分别输入每位闲家和庄家支付额。均不含本场和供托，系统自动另加，支持多响、撤销和局数推进。直接输入不核验役种，包牌请使用选役模式。
