# iPhone 使用说明

本版已针对 iPhone Safari 调整安全区、键盘弹出后的可见高度、全屏弹窗、后台滚动锁定与关闭后的滚动恢复，并提供主屏幕图标与网站离线缓存。

## 推荐入口
将程序目录发布到 HTTPS 静态网站后，在 iPhone 的 Safari 打开网站地址，通过分享菜单添加到主屏幕。当前交付是适配后的程序文件，尚未发布网站，因此压缩包不是可直接访问的网址。

本地 HTML 文件在聊天软件或“文件”App 内可能仅作为预览打开，不保证执行脚本。网页版通过 Safari 打开是本版的主要 iPhone 使用方式。

## 离线与存档
网站首次联网完整加载并完成缓存后，可使用已缓存的应用文件；首次打开仍需联网。浏览器仍可能回收离线缓存与本地存档，请保留导出的备份。添加到主屏幕前后如使用了不同存储环境，记录可能不共享。

## 验证范围
已通过可见视口与键盘尺寸模拟、弹窗滚动恢复、主屏幕图标尺寸、缓存文件完整性、便携版功能和手牌结算检查；没有真实 iPhone 设备，因此尚未完成真机触控与视觉测试。
