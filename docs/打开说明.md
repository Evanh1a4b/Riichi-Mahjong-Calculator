# 雀算统一文件夹

- **程序/index.html**：双击启动最新版；请保留程序文件夹内的所有文件。
- **程序/使用说明.md**：完整操作与规则说明。
- **雀算最新版.zip**：最新版程序的便携压缩包。
- **历史版本/**：此前交付的各版压缩包，供回溯。

最新版已合并此前的计分、四家记分台、点差表、自定义规则、四语言、独立手牌模块、包牌比例、犯规继续与强制过庄、选役重置和结算变化表。

本次更新将终局分统一显示为一位小数，例如 `60.0`、`-12.3`；内部计算保留原精度。

移动本地文件路径可能影响浏览器对原存档的访问。旧路径有未完成对局时，可将程序内容复制回原路径使用，或保留已导出的记录。

手机版单文件：程序/雀算手机版.html。手机操作见手机使用说明.md。


iPhone适配版见雀算-iPhone适配版.zip，使用方式见iPhone使用说明.md。
