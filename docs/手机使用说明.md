# 手机使用

程序已支持手机窄屏、横屏、触屏按钮、全屏弹窗和横向滑动点差表。

- 手机便携文件：程序/雀算手机版.html。所有脚本、样式和手牌模块已内嵌，传送这一个文件即可。
- 完整版：程序/index.html，需保留同文件夹的其他文件；也可将整个程序目录发布为静态网站，再通过手机浏览器访问网址。
- 若聊天软件、文件管理器或系统的HTML预览不执行脚本，请使用支持脚本的浏览器打开；若仍受本地文件限制，请通过网站地址使用。手机本地预览环境不能由此文件强制启用脚本。
- 本地文件版与网站版的存档通常相互独立，换设备前请导出备份。

逻辑验证已覆盖便携文件的内嵌依赖、手牌模块、结算、撤销、语言切换及规则设置；尚未在真实手机上完成视觉与浏览器兼容性测试。
